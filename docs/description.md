Renders Mermaid diagrams (flowcharts, sequence, class, state, ER, gantt, pie,
git graphs and more) right inside JCode, fully offline via a bundled Mermaid
engine. Long-press a .mmd/.mermaid file or a Markdown file and choose
"Preview Mermaid Charts" for a chart-by-chart view with zoom and source
inspection, or "Preview Document (Inline Charts)" to read the whole Markdown
document with every mermaid fence rendered in place. The preview follows the
active editor tab and refreshes automatically when files are saved. With this
extension installed, JCode's built-in Markdown preview also renders mermaid
fences inline instead of showing them as plain code.
